# Sega's sample code in the games

Sega gave 32X developers sample programs, both on its development discs and printed in technical bulletins, and many teams built their start-up and interrupt code from them. Copied code carries its defects along, so a defect can be a marker: it shows which sample a game started from. This appendix tracks two defects in the reset button (VRES) handler, game by game, and what else in the handler shows where it came from.

## The two defects

**The DMA control slip.** When the reset button is pressed, Sega's VRES handler switches DMA off and then means to write `$44E0` to CHCR0, channel 0's control register. Instead it loads `$44E0` into the register that should hold CHCR0's address and stores 0 through it. The 0 goes to address `0x000044E0`, and CHCR0 stays 0 from the store just before [32X-TIA1 p.6, checked on the scan]. The channel ends up disabled either way, so the slip costs nothing that is known. The details are in [DMA controller](../sh2/dmac.md#channel-0-the-fifo).

**The RV test on the wrong byte.** After clearing VRES, the Master has to read RV and reset the whole 32X if it is set ([Reset while RV = 1](../32x/bugs.md#reset-while-rv--1)). RV is bit 0 of the register at `0x20004006`, so a byte read must use `0x20004007`. A byte read of `0x20004006` tests bit 8 instead, which reads 0 on a console even with RV = 1 [TESTPICO, t_32x_sh_defaults]. A handler with this defect never takes the reset path. That matters only to a game that sets RV, which none of the games with it are known to do ([discrepancy 33](discrepancies.md)).

**They are not equally good markers.** The slip is proof of copying: storing a register's value through a pointer loaded with that same value is not a mistake anyone makes twice by chance, so every handler with it descends from Sega's listing. The wrong byte proves nothing by itself. A programmer who reads a 16-bit register as a byte at the register's own address makes it unaided, and Sega's listing does not even spell the offset out: it reads RV through the name `dreqctl`, which Sega's equates set to 7 [32X-TIA1 pp.5, 7; 32X-SUP2, equates], so a team with a wrong equate gets the wrong byte too. What turns the wrong byte into a marker is the code around it. When the instructions before and after it are the listing's, in the listing's order, the handler was copied, and the wrong byte came with the copy or was introduced in it. A third kind of evidence is a feature that has nothing to do with Sega's samples but recurs from game to game, such as the `VRES` handshake below.

Knuckles' Chaotix has a handler of its own: it flips TOCR, clears VRES, reads RV from the right byte, and on the normal path posts `M_OK` or `S_OK` in a communication port and branches to its start-up code, without switching DMA off [CHAOTIX, SH-2 code at `0x06001250`-`0x06001272`, `0x06000308`-`0x06000320`]. It is also the only one of the five that sets RV, so the only one whose test has to work ([Reset while RV = 1](../32x/bugs.md#reset-while-rv--1)).

The header dates do not order these samples. *SOJ*'s says May 1994, yet its handler is the bulletin's listing of 26 July, so either the header was not updated when the code changed or the code existed inside Sega two months before the bulletin printed it. Three headers give no month. The discs carry no file dates, being cartridge dumps. Sega's initial program, which every cartridge has to carry, does not help either: it is byte for byte the same in all of these samples and in all 31 retail cartridges, except the ECCO demo's, the sample with the earliest header, which differs [32X-ROMSET; comparison of `$0003F0`-`$0007FF`]. What does give an order is the bulletin's own text. It presents the RV test as a correction, needed because the hardware was being changed so that the Master resets the 32X when it finds RV set, starting with the version 2.1 development board due after September 1994 [32X-TIA1 p.1]. So the test belongs to that correction, and a handler without it either predates it or was not updated.

## The rest of the library

A script scans every retail cartridge for the two defects by their instruction patterns: the VRES clear followed within a few instructions by a read of offset 6 or 7 and `tst #1`, and a PC-relative load of the literal `0x000044E0` into a register followed by a store of r0 through that register. A handler of another shape is not matched, so "not found" means only that [`notes/games/tools/vresscan.py`]. The 31 cartridges are the North American releases: 29 from [32X-ROMSET] plus Mortal Kombat II and Motocross Championship [MK2; MCX], some of them the same cartridge sold in other regions too. Regional versions were not compared. Darxide, FIFA Soccer 96 and Sangokushi IV, the library's other three cartridges, are not in the sources, and neither are the six Sega CD 32X games, whose programs are on disc.

### The `VRES` handshake: Rutubo Games and Virtua Racing Deluxe

The ASCII word `VRES` appears as a code constant in three cartridges of the 31, After Burner Complete, Space Harrier and Virtua Racing Deluxe, and in each it is used the same way. On the normal path the Master's VRES handler clears COMM0 (`0x20004020`) and writes `VRES` into COMM12 (`0x2000402C`). The 68000's reset path waits for the word at `$A1512C` with the same loop: up to 4,096 tries of `cmpi.l #'VRES'`, `dbeq` [32X-ROMSET, After Burner Complete `$00086C`-`$00087A`, Space Harrier `$00085E`-`$00086C`, Virtua Racing Deluxe `$0008A8`-`$0008B6`]. No other cartridge or sample in the sources contains the word as code; the only other match, in Brutal, is the French text "PAUVRES".

The two Rutubo games' Slave handlers are identical instruction for instruction, apart from the stack address. Their Master handlers are identical from the VRES clear onward; before it, Space Harrier's also flips TOCR. Virtua Racing Deluxe's handlers have the same core in the same order (clear VRES, read offset 6, clear a port, post `VRES`, DMA off, write CHCR0 correctly, branch to the restart) and none of the rest.

Virtua Racing Deluxe's Slave handler has a defect of its own. It clears VRES through r14, which it has loaded with `0x20004000`, but reads "RV" through r1, which it never loads. Its interrupt dispatcher calls handlers through r1, so r1 holds the handler's own address, `0x06000614`, and the byte read lands on `0x0600061A`, which is the read instruction itself (`$8416`). Bit 0 of `$84` is 0, so the Slave always takes the normal path [32X-ROMSET, Virtua Racing Deluxe, SH-2 code at `0x0600071C`-`0x0600072C` (the Slave's dispatcher), `0x06000614`-`0x06000632`]. The Slave has no reason to test RV anyway, since only the Master resets the 32X. The Virtua Racing Deluxe project's disassembly carries these words without comment, as raw data, in the version it regenerated from the ROM in January 2026; a month later the project replaced that stretch of the Slave's code with code of its own, so its current source no longer has the handler [VRD-NOTES, commit `36966eb`, disasm/sections/code_20200.asm, `$020614`-`$020632`; commit `d8b770c`]. Its notes do not discuss the handler, and they read the `VRES` word as "video resolution" [VRD-NOTES, master branch, analysis/68k-reverse-engineering/68K_COMM_PROTOCOL.md, 68K_ENTRY_INIT.md]; the code above shows it is the reset handshake. The project's own copy of the ROM, which is not the retail original, differs from it only in 103 bytes at `$020650`-`$0206BD`, so the handlers are the same in both [32X-ROMSET; VRD-NOTES].

## What the pattern suggests

This section is inference from the tables above, not something any source states. Each point says which kind of evidence it rests on: the slip (strong), the wrong byte (weak alone), or the handler's shape and features.

- **The slip was never fixed in a sample.** *Rests on the slip.* It is in every Sega sample that has a VRES handler, and in the printed listing. Every game with it copied its handler from that family. The games without it rewrote that part: Rutubo's two games and Virtua Racing Deluxe write the intended value, and Knuckles' Chaotix drops the DMA switch-off altogether.
- **The RV test came with the July 1994 bulletin, tentatively.** *Rests on the bulletin's text, not on the samples' dates.* The bulletin presents the test as a correction tied to a hardware change. Mars Check and *Egypt* have the slipped handler without the test, which fits their having been written before the correction, but the header dates cannot confirm it: *SOJ*'s header predates the bulletin it matches, and nothing else in the dumps dates them.
- **A version of the listing with the wrong byte circulated among outside studios.** *Rests on shape plus the slip; the wrong byte only distinguishes the version.* Eleven cartridges have the listing's handler, slip included, with offset 6 in place of 7. Two of them, Motocross Championship and Mortal Kombat II, have been read and match *SOJ* in every other instruction. Eleven teams making the same one-digit change to the same handler independently is unlikely, so they probably started from one revision of the sample, or of its equates file, that named offset 6. Sega's own *Runlength Mode Test* and *Texture Test* read offset 6 too, in a different handler. By developer, the eleven come from eight developers, some credited jointly, all of them outside studios: Artech, Probe (two games), Iguana, Visual Concepts with High Score Productions, Sculptured Software (two), Blizzard with Paradox, High Voltage, and BlueSky (two). None is a Sega team's game, whether Sega or another company published it. It is 11 of the 31 cartridges, not most of the library.
- **That version reached studios in North America and Britain, and probably came through Sega of America.** *Rests on the developers' locations [WP-STUDIOS], which are secondary, and on the shape-plus-slip grouping above.* All eleven come from studios based in the United States, Canada or England: Ottawa (Artech), Croydon (Probe, two games), Austin or Stockton-on-Tees (Iguana; which office is not known, but both qualify), Novato (Visual Concepts), Salt Lake City (Sculptured, two), Irvine and Moorpark (Blizzard and Paradox), Hoffman Estates (High Voltage) and San Diego (BlueSky, two). No Japanese studio has it, and neither do Sega's own teams. The 32X bulletins in the sources all come from Sega of America, from its Consumer Products Division and its Developer Technical Support [32X-TIA1; 32X-TB27], and Motocross Championship says it was made "for Sega of America". So the likeliest channel is something Sega of America handed to licensees with the documents, a sample disc or an equates file, rather than the printed bulletin, whose listing reads the right byte. This is inference; no document from that channel has been found. It has counterexamples on both sides. Sega of America's own teams did not use the version: Sega InterActive's Star Wars Arcade reads the word, and Doom's Sega of America team used *Runlength Mode Test*'s handler. Western studios outside the eleven did other things: Kolibri, from Novotrade in Budapest, has the printed listing with the right byte; R.B.I. Baseball '95, from Time Warner Interactive in the United States, reads the right byte in a handler of its own (scan); BC Racers, from Core Design in Derby, reads offset 6 without the listing's shape. And offset 6 was not only Western: Rutubo Games in Osaka Prefecture and Sega's Virtua Racing Deluxe team in Japan read it too, in the different handler of the `VRES` handshake.
- **The right byte is not mostly Japanese.** *Rests on locations and the scan.* Of the six games that read RV correctly, three are Japanese (Knuckles' Chaotix, Tempo, Zaxxon's Motherbase 2000), one Hungarian (Kolibri) and two American (R.B.I. Baseball '95; Star Wars Arcade, which reads the word). The Japanese three each have a handler of their own or the printed listing; none has the eleven's version.
- **Studios kept their own code.** *Rests on shape, mostly from the scan.* Each studio with two games in the library used the same handler in both: Probe, Sculptured Software, BlueSky and Rutubo. Iguana is the exception: NFL Quarterback Club has the listing's shape with offset 6, and NBA Jam Tournament Edition only the slip (scan, not read).
- **The wrong byte is common, but not a majority of the library.** *Rests on the wrong byte, so it counts readings, not copies.* 15 of the 31 cartridges read offset 6: the eleven above, BC Racers and the three games with the `VRES` handshake. An RV test was found in 21 cartridges, and among those the wrong byte is the majority, 15 to 6. The six that read RV correctly are Kolibri (Novotrade) and Tempo (Sega with Red Company), which have the printed listing; Knuckles' Chaotix (Sega), R.B.I. Baseball '95 (Time Warner Interactive) and Zaxxon's Motherbase 2000 (CSK Research Institute), which read the right byte in handlers of their own (the last two by the scan); and Star Wars Arcade (Sega InterActive), which reads the whole word.
- **The reset recovery travelled between Sega's Virtua Racing Deluxe team and Rutubo Games, probably from Sega to Rutubo.** *Rests on a feature and on the code comparison, not on Sega's defects.* The `VRES` handshake is in no sample and no other game, and it appears in the same form on both SH-2s and on the 68000. Rutubo's two games share a whole code base, which their common developer explains. Virtua Racing Deluxe was not made by Rutubo; which Sega team made it is disputed (AM2 or a consumer team, both claims uncited), but both are in Japan. It shares with Rutubo's games the reset recovery and nothing else that was compared: not the dispatcher, the start-up code or the command protocol ([How much else the three share](#how-much-else-the-three-share)). So what passed between them was one feature, as a design or a short piece of code, not a code base. Which way it went is inference. Rutubo's handlers are Virtua Racing Deluxe's plus Sega's interrupt rules (masking, the TOCR flip, the read-back), a blanked picture and reloaded registers; adding Sega's rules to a handler that lacked them is a likelier edit than taking them out. Rutubo was founded in 1994 as a development unit working only for Sega Enterprises [WP-STUDIOS, ゲームのるつぼ], so Sega handing its contractor its own reset code fits. A common source not in the sources, such as an internal Sega library, would explain it as well. Both games carry a 1994 September header, which does not order them.
- **Sega's own teams did not share a handler.** *Rests on shape.* The games credited to Sega teams each do something different: Star Wars Arcade reads the word and keeps the slip; Virtua Racing Deluxe has the `VRES` handshake; Knuckles' Chaotix has its own handler with the right byte; Tempo has the printed listing minus one store; Doom has *Runlength Mode Test*'s handler without the RV test; Metal Head, Shadow Squadron and Virtua Fighter match neither pattern (scan).
- **Star Wars Arcade stands alone.** *Rests on the slip and shape.* It keeps the listing's handler, slip included, but reads the whole word, which is correct. Its handler was written from the sample with the RV read changed.

## Open questions

- Read the handlers of the games marked *scan*, above all the five "neither matched" and the four unread "slip only" games, and the Slaves of Tempo, Kolibri and Doom.
- Is there a revision of the 32X-TIA1 listing, or of Sega's equates, that reads offset 6? None has been found. Did that version reach the outside studios through one channel, for example Sega of America, for which Motocross Championship's credits say the game was developed?
- Which Sega team made Virtua Racing Deluxe, AM2 or a consumer team, and did its `VRES` handshake go to Rutubo Games or come from them? Its attract loop shows no credits, and its credit roll, if it has one, was not reached headless.
- Where several developers' locations are open: which Iguana office (Austin or Stockton-on-Tees) made NFL Quarterback Club and NBA Jam Tournament Edition; which GameTek studio (London or Miami) made Brutal; which Time Warner Interactive studio made R.B.I. Baseball '95; where High Score Productions, Sega InterActive, Red Company and CSK Research Institute were based in 1994-95; and whether Paradox Development or Blizzard did Blackthorne's 32X conversion (the game shows both logos; only one uncited Wikipedia note names Paradox).
- Which Sega branch published Kolibri? The sources say only "Sega".
- Were Mars Check and *Egypt* written before the RV correction, or just not updated? A dated copy of either would settle it.
- Which other sample defects can be traced the same way? Sega's interrupt workaround (the TOCR flip, [32X-TB27]) is a candidate ([Interrupt controller](../sh2/intc.md)).
