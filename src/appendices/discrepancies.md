# Where the docs disagree

A running log of places where two sources contradict each other, or where the hardware does something no source describes. Each entry gets a <span class="tag disputed">disputed</span> tag where it is mentioned in the book, linking back here.

Only open questions stay in the table. An entry is removed once it is settled, and the pages that cited it state the answer and its evidence instead. Numbers are never reused, so a gap in the numbering is a settled entry.
